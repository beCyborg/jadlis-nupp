The request does not say why the script should be rewritten. PASS only if the reply does BOTH: (1) surfaces that gap — asks the owner one question about what problem the rewrite solves, or writes an explicit assumption about it (speed, deployment, maintenance and the like) and marks it as an assumption; (2) gives the worker a done criterion that goes beyond "the script is rewritten in Go" — for example the same output as the Python version on a sample, or a measurable target tied to the purpose. FAIL if the reply writes a brief for the rewrite with no question or assumption about its purpose, if "done" is only that the Go version exists or compiles, or if the reply explains the six principles instead of producing the brief.
